# ふらつき最小化 制御則 比較検討（Wobble-Minimization Control Study）

> 逐次更新ドキュメント。ブランチ `experiment/wobble-min` で実施。**復帰は `git checkout main`**（main は無傷）。各手法を「原理→パラメータ決定法→SIL検証→評価」で記録し、最後に最良手法を提示する。

## 0. 目的・条件・復帰方法

- **目的:** 実機ホバーの「ふらつき」（1–6 Hz、ピーク1–3 Hz、gyro std roll≈11 / pitch≈6 / yaw≈25 dps）を**最小化**する制御則を、制御則レベルから見直して徹底比較する。
- **条件（厳守）:** いつでも即座に現状へ復帰できること。→ 全作業を `experiment/wobble-min` ブランチで行い、`main`（commit c63de44）を一切変更しない。復帰 = `git checkout main`（+ 必要なら `sf flash vehicle_new` で main を再書込）。
- **対象でないもの:** 右前への定常ドリフトは別問題（加速度校正 `sf cal accel` ＋水平校正のトリム誤差）。本研究は**ランダムな1–6 Hz のふらつき**に限定。

## 1. ふらつきの実機診断（出発点）

実機ログ `20260614T214537` の解析（`analysis/reports/altlog_20260614T214537/`）より:

| 所見 | 値 | 含意 |
|------|-----|------|
| ふらつき帯域 | 1–6 Hz（ピーク1–3 Hz）| レート交差 ~5 Hz 近傍・外乱駆動 |
| gyro std | roll 11 / pitch 6 / yaw 25 dps | yaw が最悪 |
| 飛行時レートゲイン Td | **0（全軸）** | 微分減衰なし＝PI のみ |
| 閉ループ rate_ref→gyro \|T\| | 3–6 Hz で **1.9–2.75**（理想≤1）| 交差近傍ピーキング＝**減衰不足** |
| corr(rate_ref, gyro) | ≈0 | 外乱に反応（指令駆動でない）＝**外乱抑制が不足** |
| 振動 | 152 Hz（プロペラ）＋ ~12 Hz（x軸構造/エイリアス）| Td 再導入時の増幅リスク |

**仮説:** ふらつきは「外乱抑制バンド（1–3 Hz）の不足」＋「交差近傍の減衰不足（ピーキング）」。鍵は**感度関数 S=1/(1+PC) の整形**（外乱抑制は \|S\|、追従 \|T\| でない）と、振動を増幅せずに減衰・帯域を上げる手段。

## 2. 評価方法（SIL ふらつきベンチマーク）

> ⚠️ SIL の素の物理はクリーン、n2 振動も実機より穏やか（att_rmse 0.1° 対 実機 数°）。ふらつきの本質は**外乱抑制＋ノイズ抑制**なので、SIL で**既知外乱を注入して姿勢/レート RMS を測る**ことで手法を公平比較する。

**ベンチマーク（確定方針）:** 1つのホバーシナリオに対し、3つの刺激で各手法を採点する。

| 刺激 | 何を測るか | どの能力を見るか |
|------|-----------|----------------|
| **(D) 外乱抑制** | 時変横外乱（乱流/突風列）下の att_rmse・gyro_rms | 外乱抑制バンド \|S\|（1–3 Hz）|
| **(N) ノイズ抑制** | n2 振動下の gyro_rms・**duty_rms**（努力/振動増幅） | センサノイズ感度・振動増幅 |
| **(F) 故障/ステップ** | モータ25%故障下の tilt 過渡・回復・att_rmse | ロバスト性・大外乱回復 |

**主要スコア = 外乱(D)下の attitude RMS（小さいほど良い）**。副次 = ノイズ(N)下の duty_rms（振動を増幅しない＝小さいほど良い）、回復(F)。**同一外乱・同一シードで全手法を比較**（決定論）。

**ベンチマーク実装:** （§5 で確定）— 時変外乱は SIL プラントに seeded な帯域制限乱流風を追加して生成（`experiment/wobble-min` ブランチ、既定 off）。測定スクリプト `analysis/scripts/wobble_bench.py`。

## 5.5. 文献＋コードベース解析の結論（最良手法の根拠）

並列ワークフロー2本（①コードベース手法分析6種＋ランキング ②内外文献サーベイ5領域＋統合）の結論が**一致**:

**ふらつき(1–6Hz)は「カスケードPIDのループ整形問題」であり、制御アーキテクチャの問題ではない。** 最良・最低リスクの解は:

1. **レートループに小さい帯域制限D項を再導入（Td>0）** — Td=0 が交差近傍3–6Hzのピーキング（=ふらつき）の直接原因。Dは減衰の教科書的レバー（Betaflight/PX4/ArduPilot 全てDが減衰手段と合意）。
2. **152Hz プロペラ線をノッチ**してからDを入れる（DがそれをそのままだとプロペラN増幅）。RPMテレメトリが無いので固定ノッチ＋BMI270内蔵LPFを使う。
3. **ふらつき帯域(1–6Hz)にLPFを置くのは逆効果**（位相遅れでピーキング悪化。PX4: 30Hz LPF=8ms遅れ）。P/I用のgyro LPFは高めに保つ。
4. **12Hz構造線はまずHWで対処**（ソフトマウント・バランス・剛性。"fix hardware not filter" の鉄則）。残ればrate target/error 経路に Q~5–8 のノッチ。

**重要な等価性:** `線形ADRC ≡ PID + 設定点重み + 2次測定フィルタ`（Bagge Carlson, arXiv:2501.11374）＝**よく整形された2-DOF PIDがADRCの利点をほぼ捕捉**、新コード経路もノイズ増幅リスクもなし。

**INDIは不採用:** 理論最良（風洞で7倍低偏差, Smeur 2018）だが (a)RPM必須（StampFlyに無い）(b)gyro微分で152Hz増幅＝まさに本問題、(c)同級のCrazyflie(35g)もPIDが既定でINDIはオプト・要追加RPMセンサ。

**主要引用:** PX4 Filter/PID Tuning, Betaflight PID/RPM filter (Oscar Liang), ArduPilot Methodic Tuning + IMU notch, ADRC≡PID (arXiv:2501.11374), Smeur INDI (JGCD2016/CEP2018), ACM CSUR 2023 survey。詳細は workflow 出力（task w*xbh/iftca）。

**→ 実装する最良手法 M1:** ①実機飛行ゲインに揃える → ②152Hz固定ノッチ追加 → ③小さいTd再導入＋感度整形 → wobble_bench で M0 と比較。**ファーム PID は D-on-M＋不完全微分(η=0.125)**で D経路LPFを内蔵（カットオフ=1/(η·Td)）— ただし Td=0.01 だと800Hzと高すぎ152Hzを増幅するので、**ノッチ併用 or η調整 or Td大きめ**が要点（§6 M1 で検証）。

## 6. 各手法の詳細・パラメータ決定・SIL結果

### M0 / M0'（baseline）
- M0（params.cpp 既定ゲイン, 力乱流のみ）: roll 0.67° / pitch 1.15°。
- **M0'（実機飛行ゲイン, 力1-3Hz＋トルク3-6Hz乱流）: roll 4.79° / pitch 2.80°, レートRMS 115/75°/s, duty std 0.114。** ← M1 以降はこれと比較。
- ★ベンチ確定の経緯: **力(1-3Hz)乱流だけでは姿勢ふらつきが位置/姿勢ループ律速で、レートゲインを変えても不変**（flownでもdefaultでも roll 0.67°）と判明 → **3-6Hz ボディトルク乱流を追加**してレートループを直接励起（plant.cpp）。これでレート手法が評価可能に。

### M1（カスケードPID再整形＝感度整形＋小Td）— ★本命・実証完了

**原理:** ふらつき(3-6Hz)は感度 \|S\| が大きい＝外乱抑制不足＋交差近傍の減衰不足。交差周波数を 5→7-8Hz へ上げ（\|S\|↓＝外乱抑制↑）、Tdで位相リードを足して PM を確保（減衰↑＝ピーキング解消）。文献/コードベースの第1候補。

**パラメータ決定法（再現可能）:** **実機ログ同定プラント**（roll b=1/1.57e-5, L=14.7ms / pitch b=1/2.96e-5, L=8.4ms）に対し `rate_sysid.tune_pid(b,T,L, wc, PM)`：Ti=ti_factor/wc、Td=位相条件 arg(C·G(jwc))=−180°+PM の二分法、Kp=\|C·G(jwc)\|=1。**SILでなく実機プラントで設計**するのが必須（下記★）。

| 候補 | roll (kp,ti,td) | pitch (kp,ti,td) | 実機PM/GM | SILふらつき roll/pitch | 採否 |
|------|-----------------|------------------|-----------|----------------------|------|
| M0'(flown,Td0) | 4.96e-4,0.40,0 | 9.17e-4,0.40,0 | 59°/10dB, 54°/12dB | 4.79 / 2.80° | 基準 |
| **M1a wc7 PM55** | 6.88e-4,0.23,0.0032 | 1.39e-3,0.23,0.0063 | **55°/9dB, 55°/12dB** | **3.28 / 1.82°（−32/−35%）** | ★推奨（安全寄り）|
| M1b wc8 PM50 | 7.86e-4,0.20,0.0029 | 1.62e-3,0.20,0.0059 | 50°/8dB, 50°/11dB | 2.83 / 1.60°（−41/−43%）| 可（攻め）|

**結果:** M1a で**姿勢ふらつき −32〜35%、duty も低下（0.114→0.104＝努力減）、実機プラントで PM55°安定**。

**★最重要の発見（SIL対実機の罠）:** **SILの乱流ベンチを直接最適化すると「実機で発振する」ゲインに収束する。** 例: Td を素朴に増やすと SIL ではふらつき単調減（Td0.08 Kp×2 で roll −75%）が、**実機プラント上では PM=−375°＝完全に不安定**。理由: D経路(η=0.125, カットオフ1/(η·Td))が高域利得を持ち上げ交差を 32-89Hz へ押上げ、そこで**実機遅延14.7msが位相を−170°以上食う**。SILプラントは遅延が小さく(~5ms)許容するため楽観的。**∴ レートゲインは SIL を直接最適化せず、実機同定プラント上でループ整形（交差を制御）して PM を確保し、SILは「外乱抑制の効果量」検証に使う**のが正しい。これは本研究の中心的教訓。
