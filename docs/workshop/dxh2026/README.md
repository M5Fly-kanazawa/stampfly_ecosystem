# DXH 高校教員向け体験講座 2026 (dxh2026)

> DXH（高等学校DX加速化推進事業）の高校教員向け StampFly 体験講座（2026-07-18・07-19）で使用する文書一式のディレクトリです。本ディレクトリの大半は運営・講師向けの内部文書であり、参加者（高校教員）に配布する資料は `handout.md`（完成。スクリーンショットはリハーサルで撮影・差し込み予定）が対象です。

## 1. 概要（開催情報）

| 項目 | 内容 |
|------|------|
| 主催 | DXH（高等学校DX加速化推進事業） |
| 日程 | 2026-07-18（土）・2026-07-19（日）の2日間（各日独立開催・同一内容） |
| 時間 | 各日 2時間（120分・1コマ） |
| 定員 | 10名／日 |
| 対象 | 高校教員（プログラミング言語の使用経験が望ましいが、初心者も含む） |
| 機材 | Windows 11 PC（Core i5）＋ StampFly 本体＋ Atom JoyStick コントローラ＋ USB-Cケーブル（データ通信対応）。全て大学貸出・1人1セット＝1人1台演習 |
| 告知4テーマ | ① ドローン操縦体験　② 開発環境のインストール　③ プログラム書き換え体験　④ モータの制御 |
| 準備締切 | 2026-07-17 |

告知4テーマは `curriculum.md` の学習目標・タイムテーブルにそのまま対応する（① は「操縦体験」パート、②は「開発環境+ビルド不要書き込み」パート、③④は「プログラム書き換え・モータの制御」パートにまとめて割当）。

## 3. 状態

**教材一式は完成済み、リハーサルによる実測値の確定待ちです。** スクリーンショット（`handout.md` 用）や所要時間などの実測値は、準備締切（7/17）までに実施する貸出PCでのリハーサルで確定します。未確定の箇所は各文書内で【リハーサル実測】【リハーサル確認】と明記しており、断定的な数値・挙動をリハーサル前に記載することはありません。リハーサルで判明した値は、`curriculum.md` および `handout.md` の該当箇所へ反映します。
