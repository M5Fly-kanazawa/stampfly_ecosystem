# DXH講座 機材チェックリスト

> **DXH講座運営用の内部文書。** 高校教員には配布しない。講師・運営スタッフ専用。

## 0. この文書について

2026-07-18(土)・07-19(日) 開催の DXH 高校教員向け体験講座（各日定員10名・各2時間）で使用する機材の数量・チェックリストをまとめる。準備締切は **7/17**。1人1セット演習のため、機材はすべて10セット分（+予備）を必要とする。

セットアップ手順の詳細は `docs/workshop/dxh2026/setup-loaner-pc.md` を参照。

### バッテリー必要本数の根拠【要確認: 保有本数】

- 1本あたりの飛行時間は約4分
- 操縦体験は25分の枠内で「5名×2交代（飛行約10分×2グループ）」— 1グループあたり約10分の飛行時間を割り当てる
- 1本（約4分）では1グループ分（約10分）をカバーできないため、**1セットあたり最低2本**（1本消耗中にもう1本へ交換できる本数）を用意し、電圧低下（シアン点滅＋警告音）時に即座に交換できるようにする
- 交換の空白時間や電池不良に備え、さらに予備本を確保することが望ましい
- 実際に大学側で保有している本数・充電サイクル所要時間は【要確認】。保有本数が不足する場合は、休憩中の急速充電運用またはグループあたりの飛行時間短縮で調整する

## 2. 前日チェックリスト

- [ ] `setup-loaner-pc.md` の手順が全11台（10台＋予備）で完了していることを確認
- [ ] 全セットのペアリングが完了し、クロスペアリングがないことをコントローラLCDのMAC表示で再確認
- [ ] 全バッテリーを満充電（4.2V）にする
- [ ] StampFly本体・コントローラの数量を機材一覧表と照合
- [ ] プロペラガードの破損・変形がないか全機体を目視確認
- [ ] 模様付きマットを飛行エリアに敷設し、光学フローでの位置保持（POS_HOLD）が安定することを1台で確認
- [ ] ネット／フェンス／区画テープで飛行エリアと待機エリアを分離
- [ ] プロジェクタ・HDMIケーブルの接続確認、スライド投影テスト
- [ ] 電源タップ・延長コードを配置し、PC10台＋充電器が同時に電源を取れることを確認
- [ ] 印刷物（配布資料12部・アンケートQR掲示物）を準備
- [ ] 救急セット・予備プロペラの在庫確認
- [ ] C:\StampFly\ 配下のフラッシャ・binファイルが全PCに配置済みであることを再確認

- [ ] 全PCの電源を入れ、`sf doctor` が全OKであることを1〜2台で抜き取り確認

## 4. 終了後チェックリスト

- [ ] `setup-loaner-pc.md` §4「講座終了後の復元手順」に従い、各機体にリリースFWを書き戻す

- [ ] 各セットでPOS_HOLDによる動作確認フライトを実施
- [ ] 全バッテリーを充電（充電中は目を離さない）
- [ ] 機材一覧表と数量照合し、破損・不具合の有無を記録
- [ ] 破損・不具合があれば大学側へ報告
- [ ] 保護メガネ・マット・ネット／フェンス等の備品を撤収・収納
- [ ] アンケート回収状況を確認
- [ ] セット番号ラベルの扱い（剥がす／残す）を確認の上、返却準備を完了する
