\begin{frame}{② Web フラッシャの手順}
  \begin{enumerate}\small
    \item 機体の電源を入れ USB-C で PC に接続
    \item \footnotesize\url{https://m5fly-kanazawa.github.io/stampfly_ecosystem/flash/} を開く（Edge/Chrome）
    \item 「StampFly 本体」カードの「インストール」をクリック
    \item ポート選択ダイアログでポートを選び「接続」
    \item INSTALL 実行 $\to$ 進捗\% $\to$ 完了
    \item 機体が自動再起動。起動音が終わるまで水平静置（ジャイロ校正）
  \end{enumerate}

  \vspace{0.4em}

  \begin{alertblock}{重要}
    \footnotesize 書き込むと機体の設定保存領域（NVS）も工場出荷状態に戻り、ペアリング情報が消えます。\\
    本講座はこの後に飛行しないため問題ありません（再ペアリングは講師が行います）
  \end{alertblock}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{② よくある失敗と対処}
  \begin{table}
    \centering\small
    \begin{tabular}{ll}
      \hline
      \textbf{症状} & \textbf{対処} \\
      \hline
      ポートが選べない/繋がらない & ケーブルを交換（充電専用ケーブルは不可） \\
      書き込みが進まない/失敗する & ポートを使う他アプリを閉じる \\
      それでも失敗する & 機体の BOOT ボタンを押しながら\\
                       & USB を挿し直して再 Install \\
      \hline
    \end{tabular}
  \end{table}

  \vspace{0.5em}

  \end{exampleblock}
\end{frame}
