# V(T) モータ推力→電圧写像の飛行ログ同定 — 結果報告

生成日: 2026-07-29 / リポジトリ変更なし（分析のみ、成果物は本ディレクトリのみ）

## 結論（要約）

1. **Step1 自己検証は PASS**: IMU（クォータニオン姿勢＋加速度、バイアス補正）から
   独立再構成した実推力 `T_actual = m·f_up` は、85 個の定常ホバー区間（9 日付）で
   `T_actual/(m·g)` の平均 **1.0020**、区間平均のばらつき **0.0099**（約1%）——
   符号規約・バイアス処理は正しい。
2. **準静的抽出（77k サンプル、11日付・42ログ）は duty 0.21〜0.81 の範囲を持つが、
   実推力 T はホバー値近傍（中央値比 ±10%程度）にほぼ張り付く**。これは抽出条件が
   厳しすぎたためではない——傾き上限を30°、|vz|上限を2.0m/sに緩め、さらに
   duty 整定条件を完全に外す（過渡混入を許容する上限ケース）まで緩和しても
   T のレンジは中央値比0.196→0.233までしか広がらず、むしろ T と V̄ の相関は
   0.088→0.017 へ悪化する（`sensitivity_sweep.csv`）。ALT_HOLD/POS_HOLD 飛行は
   定常状態でニュートンの法則により T·cosθ≈mg に拘束されるという**物理的事実**が
   原因であり、閾値の選び方の問題ではない。
3. **したがって {α,β,γ} は個別には同定不能**: 全日付・プールいずれも
   corr(α,β) ≈ −0.995〜−1.000、計画行列の条件数 1e6〜1e9。日付別の α 点推定値は
   −25〜+4050 の範囲に暴れる（物理的に無意味）。2分割ホールドアウト
   （早期6日付で学習→後期5日付のホバーで検証、およびその逆）でも
   implied_corr が **1.21 と 0.84**（約40%の食い違い）とセッション間で
   全く汎化しない。
4. **α と β の個別分離は不可能だが、実測データが密集する動作点（ホバー近傍）での
   V(T) 値そのものは頑健に求まる**: T=0.0908N/モータ（ホバー相当）における
   飛行整合 V ≈ **2.510V**。ベンチ理論値 2.680V（+6.4%高い＝ベンチのまま使うと
   過大電圧＝要下方補正）、旧ファーム理論値 2.411V（−4.1%低い＝要上方補正）。
5. **この結果は前回セッションの `ct_switch_study_20260727`（duty逆算＋ホバー
   85区間のみ、T=mg仮定）と手法が全く異なるにもかかわらず、ほぼ同じ数字で
   独立に裏付けられた**: 旧チェーン corr 前回 1.083±0.064 → 本研究
   1.047±0.088（日付別平均）/1.066〜1.070（プール点推定）。新/ベンチ
   チェーン corr 前回 0.909±0.053 → 本研究 0.879±0.074（日付別平均）/
   0.894〜0.897（プール点推定）。**2つの独立な方法が同じ~9〜12%のギャップに
   収束**——単なる解析コードのバグではなく、実機の物理的な特性である可能性が
   高い。
6. **ゲージ閉鎖の提案**: α,β を飛行データから再フィットするのではなく
   （ノイズを信号として報告することになる）、ベンチ実測形状
   `{Ct=6.7e-9, Am=4.279e-8, Bm=5.682e-4, Cm=9.92e-3}` はそのまま維持し、
   `hover.thrust_corr` の既定値を **約0.90**（レンジ 0.84〜0.92）に設定する
   ことを提案する。これは前回スタディの提案（1.12→約0.90）を**別手法で
   再確認**するものであり、新しい主張ではない。

## 1. 手法と自己検証（Step 1）

### 1.1 推力再構成

ファームウェアの ESKF（`eskf_core.cpp`）自身が使っている式をそのまま踏襲した:

```
accel_ned = R(q) * (accel_raw - accel_bias)     # R = body→NED 回転行列 (Quat::to_dcm 移植)
f_up = -accel_ned_z                              # NED z が下向き正のため、上向き比力は符号反転
T_actual = m * f_up                              # m = 0.037 kg
```

`q` は body→NED（world-from-body）のクォータニオンで、`predict()` 内の
`vel_ += (accel_ned + gravity) * dt`（`gravity=[0,0,+g]`）から一意に規約が
確定する。ログの `imu.accel`/`imu.accel_raw` は配線コード上**同一ソースの
コピー**（`data_stream_wire.hpp` の `UnifiedPacketBuilder::begin()` を確認）
であり、バイアス補正は別途 `accel_bias`（ESKF 推定値、ログに float 単位で
収録済み）を差し引いて自前で行う必要がある——`accel`列が補正済みだという
誤解をしないよう一次データで確認済み。

400Hz の IMU サンプルは各 50Hz `ctrl_ref` サンプルの ±10ms 窓で平均し
（motor 振動ノイズの抑制も兼ねる）、窓内標準偏差 `f_up_std_mps2` が
5.0 m/s² を超えるサンプル（振動で汚染された窓、全体の約1%）は除外した。

### 1.2 自己検証結果

`ct_switch_study_20260727/hover_segments.py` と同一の機械的ホバー判定
（高度move std<0.02m・|vz|<0.10m/s・スティック中立・duty非飽和・1.0秒以上
連続）を再実装し、85区間・9日付・345.2秒のホバーを抽出（`step1_hover_segments.csv`）。

| 指標 | 値 |
|---|---|
| プール平均 T_actual/(mg) | **1.0020** |
| 区間平均のばらつき（日付間・区間間） | 0.0099 |
| 区間内ばらつきの平均 | 別途 `step1_falsification_result.json` 参照 |

→ 平均が1.00に極めて近く、ばらつきも小さい。符号規約・バイアス処理は
正しいと判定し、Step 2 以降へ進んだ。

## 2. 準静的区間の抽出（Step 2）

### 2.1 抽出基準（結果を見る前に固定）

| 基準 | 値 | 根拠 |
|---|---|---|
| duty | 0.08〜0.92 | armed・非飽和 |
| 傾き | <10° | 鉛直投影の妥当性（cos10°=0.985、誤差1.5%以内） |
| \|vz\| | <0.8 m/s | 準静的（大きな遷移を除外） |
| duty 整定 | 直近4サンプル（80ms）の max-min < 0.01 | モータ搬送遅延 τ≈16ms
   （コミット `bb409e93`）の約5τ。1次遅れなら約99%整定に相当。3τ(48ms)〜
   5τ(80ms)の保守側（安全側）を採用 |
| IMU窓QC | f_up_std_mps2 < 5.0 | 窓内振動汚染サンプル除去（99パーセンタイル近傍） |
| モード | 全モード（ACRO/STAB/ALT/POS） | ただし選定ログにACROは0秒、STABは5.3秒のみ
   （実質 ALT_HOLD/POS_HOLD 支配） |

ログ選定は `ct_switch_study_20260727` と同一の固定基準（2026-06/07月・
ALT/POS_HOLD 合計15秒以上）を独立に再計算し、42ログ・11日付（前回の9日付に
加え 2026-06-18/19 も対象、前回はホバー区間ゼロだったため除外されていたが
本研究は準静的サンプルが取れたため含む）。

### 2.2 抽出結果 — duty レンジは広いが、推力レンジは狭い

- **n=76,835 サンプル、11日付、42ログ**。duty 実測レンジ 0.210〜0.812
  （指示の0.08下限には届かず——後述のとおり物理的制約）。
- **T_per_motor_N は 0.0908N（ホバー値）中心に、5〜95パーセンタイルで
  0.0806〜0.0984N（中央値比±8〜10%）にほぼ張り付く**。
- corr(duty, T) = **0.018**、corr(V̄, T) = **0.025**——duty のばらつきは
  ほぼ全てバッテリ電圧（corr(duty,voltage)=−0.82）に起因し、推力の
  ばらつきではない。

### 2.3 感度分析（結論がデータ範囲に依存しないことの確認）

`sensitivity_sweep.py` で傾き・|vz|・整定窓を段階的に緩めた:

| 設定 | n | T範囲/中央値 | corr(T,V̄) | corr(α,β) |
|---|---|---|---|---|
| 基準（本文の設定） | 76,835 | 0.196 | +0.088 | −0.995 |
| 傾き≤30° | 77,773 | 0.196 | +0.087 | −0.995 |
| \|vz\|≤2.0 | 76,892 | 0.196 | +0.087 | −0.995 |
| 整定窓なし（過渡混入を許容する上限ケース） | 98,627 | 0.228 | +0.022 | −0.990 |
| 全て緩和（傾き30°+vz2.0+整定なし） | 101,124 | **0.233** | **+0.017** | −0.989 |

**どれだけ緩めても T のレンジは中央値比0.20〜0.23の範囲に留まり、むしろ
相関は悪化する**。これは「ALT_HOLD/POS_HOLDでの定常飛行（速度一定=加速度
ゼロ）では、ニュートンの法則により T·cosθ≈mg に拘束される」という物理的
事実の反映であり、閾値設計の失敗ではない。真に広い T レンジを得るには
加速度を伴う運動（ACRO の積極的なスロットル操作等）が必要だが、選定ログ群
には ACRO 飛行がほぼ皆無だった。

## 3. フィット（Step 3）— 個別パラメータは同定不能

線形最小二乗（`V̄ = α·T + β·√T + γ` は α,β,γ に関して線形）で日付別・
プールの両方をフィットした結果:

### 3.1 プールフィット

| パラメータ | 推定値 | 標準誤差 |
|---|---|---|
| α | 22.61 | 0.66 |
| β | −12.05 | 0.38 |
| γ | 4.087 | 0.054 |

R²=0.021、計画行列条件数 4.1e6、**corr(α,β)=−0.995**。

### 3.2 日付別フィット（一部抜粋、全体は `fit_results.json`）

| 日付 | n | α | β | R² | corr(α,β) |
|---|---|---|---|---|---|
| 2026-06-21 | 12,894 | 23.9±3.3 | −12.4±2.0 | 0.058 | −0.999 |
| 2026-06-22 | 10,660 | 40.1±1.9 | −22.3±1.1 | 0.087 | −0.999 |
| 2026-06-27 | 17,710 | 25.2±0.7 | −12.0±0.4 | 0.143 | −0.992 |
| 2026-07-17 | 13,615 | 39.9±2.9 | −20.1±1.7 | 0.183 | −0.999 |
| 2026-06-19 (n=33、参考) | 33 | 4051±1636 | −2456±992 | 0.170 | −1.000 |

日付間で α は −25〜+4050 まで暴れる（`per_date_params.png`）。これは
「サンプル数が少ないから」ではなく（n=17,710のような大サンプルでも
corr(α,β)=−0.992 と強く相関）、**このデータの T レンジでは α,β の2つの
曲率パラメータを独立に決める情報量が原理的に不足している**ため。

### 3.3 頑健な量: 動作点での V(T)

α,β は個別に決まらないが、実測データが密集する T≈ホバー値近傍での
**予測値そのもの**（α,β,γ の特定の線形結合）は、デルタ法による標準誤差が
0.0004〜0.0008V と小さい（`vt_scatter_fit.png` 参照）。ただしこれは
**フォーマルな統計的不確かさ**であり、セッション間の系統的ドリフト
（4章参照）の方がずっと大きい——過信は禁物。

## 4. ホールドアウト検証（Step 4）

11日付を年代順に2分割（Fold A=2026-06-14〜22の6日付、Fold B=2026-06-24〜
2026-07-18の5日付、事前固定）した2分割交差検証:

| 学習→検証 | implied_corr（他方のホバーduty予測） |
|---|---|
| A（早期6日付）で学習 → B（後期5日付）で検証 | **1.209 ± 0.302**（範囲 0.77〜1.87） |
| B（後期5日付）で学習 → A（早期6日付）で検証 | **0.843 ± 0.148**（範囲 0.77〜1.21） |

デルタ法のフォーマルな標準誤差（0.05%オーダー）とは対照的に、**フォールド
間で約40%の食い違い**——これはセッション間の実機ドリフト（バッテリ内部
抵抗・ESC・温度・コネクタ状態）が、統計的サンプリング誤差よりずっと支配的
であることを直接示す。

## 5. ギャップの所在（Step 5）— 個別分解は不可、局所値のみ報告

α（推力/トルク係数系）vs β（Km/√Ct系）vs γ（オフセット）への分解は
corr(α,β)≈−0.995 のため**信頼できない**（ノイズを信号として報告すること
になる）。分解可能なのは実測データが存在する T レンジでの **局所的な
V(T) 値**のみ:

| T [N/motor] | 飛行整合 V | ベンチ理論 V | 差(%) | 旧理論 V | 差(%) |
|---|---|---|---|---|---|
| 0.0806 (5%ile) | 2.489 | 2.495 | −0.23% | 2.247 | +10.81% |
| 0.0908 (中央値≈ホバー) | 2.510 | 2.682 | **−6.41%** | 2.413 | +4.05% |
| 0.0984 (95%ile) | 2.533 | 2.815 | −10.03% | 2.531 | +0.09% |

狭い実測レンジ内で「傾き」がベンチとも旧とも系統的に異なるように見えるが、
この T レンジの違いは**日付/セッションと強く交絡**しており（真の意味での
同一条件下でのTスイープではない）、曲線形状の誤差の確証としては扱えない。
中央値点（ホバー相当）の−6.4%/+4.1%が最も信頼できる比較値。

## 6. 前回スタディとの独立裏付け

`analysis/scripts/ct_switch_study_20260727/`（duty逆算＋T=mg仮定、85ホバー
区間のみ）と、本研究（IMU実推力の直接再構成、76,835準静的サンプル、
duty逆算ではなく V(T) を直接回帰）は**手法が全く異なる**が、結果は近い:

| チェーン | 前回研究（85区間・9日付） | 本研究・日付別平均（10日付、外れ値日付1件除外） | 本研究・プール点推定 |
|---|---|---|---|
| 旧ファーム | 1.083 ± 0.064 | 1.047 ± 0.088 | 1.066〜1.070 |
| 新/ベンチ | 0.909 ± 0.053 | 0.879 ± 0.074 | 0.894〜0.897 |

2つの独立な方法が同じ ~9〜12% のギャップに収束——単発解析のバグではなく、
実機の物理的な特性を捉えている可能性が高いと判断する。

## 7. 残差診断

プールフィットの残差（`residual_diagnostics.png`）:

- **duty との相関 r=0.77** — ただしこれは T レンジが狭いことに起因する
  半ば同語反復的な相関（T≒一定なら残差≒V̄−定数≒duty·voltage−定数で、
  duty と直接相関するのは当然）であり、独立した構造欠陥の証拠としては
  弱い。
- **電圧との相関 r=−0.28** — 弱いが非ゼロ。線形電圧内挿の限界（負荷時
  電圧降下の非線形性）を示唆する可能性がある。
- **日付別の系統的オフセット** — 2026-06-18/19/20 で −0.18〜−0.77V、
  2026-06-29 で +0.21V という大きな系統誤差（`residual_by_date.csv`）。
  フォーマルな標準誤差（0.05V未満）よりずっと大きく、**3パラメータの
  定常状態モデルだけではセッション間差を説明できない**——バッテリ内部
  抵抗・ESC・温度等、モデル化していない要因が同程度以上の影響を持つ。

## 8. ゲージ閉鎖の提案

α,β の個別再フィットは提案しない（識別不能なノイズを信号として提示する
ことになるため）。代わりに:

```json
{
  "retain_unchanged": {"Ct": 6.7e-9, "Am": 4.279e-8, "Bm": 5.682e-4, "Cm": 9.92e-3},
  "hover.thrust_corr": {
    "suggested_default": 0.90,
    "supporting_range": [0.84, 0.92],
    "basis": "日付別平均0.879±0.074(n=10)、プール/実測点推定0.894〜0.897。前回研究の提案(1.12→約0.90)を独立手法で再確認。"
  }
}
```

**注意**: この補正はホバー動作点近傍でのみ検証済み。セッション間ドリフト
（ホールドアウトで0.84〜1.21）は補正量自体と同程度の大きさがあり、単一の
ファーム定数だけでは吸収しきれない。オンボード `hover.thrust.learn`
（既定 on、実行時オンライン補正）が引き続きセッション間残差の主たる
吸収機構であるべきで、本研究の定数はあくまで初期値の妥当性確認と位置づける。

## 再実行時の注意

`select_and_cache.py`・`extract_quasistatic.py` は本セッションの scratchpad
キャッシュパス（`cache/`）を参照する。ログ選定基準（ALT/POS_HOLD合計≥15秒、
2026-06/07月）・準静的抽出の各閾値は結果を見る前に固定した値であり、
変更する場合はその旨を明記すること。感度分析（`sensitivity_sweep.py`）が
示すとおり、閾値を緩めても結論（Tレンジの構造的な狭さ、α/β非同定性）は
変わらない。
