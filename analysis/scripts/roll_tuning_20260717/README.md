## 手法上の教訓

- **全窓の帯域比較は操縦入力に交絡される**。A/B は「スティック中立 ≥2s の連続区間」に
  限定して比較すること（選択バイアスは中立時間率が両構成で同等なことを確認して担保）
- 逆算外乱 τ_d = I·ṗ − τ_realized はジャイロノイズを外乱として取り込むため、
  シムは高Td/高kpの効果を楽観評価しがち。τ指令の3-20Hz活動量をノイズ注入の
  代理指標として併記し、最終判定は実機 A/B で行う
- 使用ログ: logs/stampfly_udp_20260717T{211648,223206,224508,224906}.jsonl（git管理外）
  ミキサーκ=6.12e-3 更新後・全て同一機体・同夜・後半3本はテクスチャマット上
