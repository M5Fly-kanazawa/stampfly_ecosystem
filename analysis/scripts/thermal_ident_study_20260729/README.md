# ホバー必要電圧 V* のフライト内ドリフト — 熱同定スタディ

生成日: 2026-07-29 / リポジトリ変更なし（分析のみ、成果物は本ディレクトリのみ）

## 0. 結論（要約）

1. **単一フライト内だけでは H1(熱)と H2(電圧)は原理的に判別不能。** 全フライトで
   corr(経過時間, Vbat) = **−0.99〜−1.00**。同じ自由度(2パラメータ)で揃えた
   「V=a+b·Vbat」と「V=c0+k·t」の当てはめ精度(AICc)はどのフライトでも
   ほぼ同点〜Vbat側がわずかに良い（後述4.1表）。これは「時間フィットの方が
   残差が小さい」という判定基準では**判別できない**ことを意味する
   （task-brief の想定どおり、共線性が支配的）。
2. **決定的な証拠は別の場所にあった: 地上待機（モータ停止）を挟んだ同一バッテリの
   2フライト対**。37.4秒・30.4秒の地上待機のあと、Vbat はほぼ変化していない
   （むしろ一方はわずかに上昇）のに、V_app は**待機前の高い値から、そのフライトの
   離陸直後（＝一番冷えていた）水準まで戻る**。H2(電圧のみ)ではこの現象を
   説明できない（Vbatの変化からは symmetric に小さな変化しか予言されない）。
   → **H1(熱)を支持する最も強い一次データ**（詳細は4.2）。
3. **フライト間・Vbat一致点の比較では 2026-06-29 のフライトだけが系統的に
   +0.2〜0.25V 高い**（4.3）。ただしこれは `vt_ident_study_20260729` が既に
   報告済みの「日付別系統オフセット」と同一の現象で、**主因はセッション間の
   `hover.thrust_corr` オンライン学習値の違い（トリム差）である可能性が高く、
   熱の直接証拠としては使えない**（交絡ありと明記）。
4. **モータ別スロープは部分的に支持**: 3フライトで4モータ中 9/12 が正のスロープ
   （符号検定 片側 p≈0.07、有意水準に届かないが示唆的）。M2 が2フライトで
   唯一の負スロープを示し、既存の別診断（`project_motor_fault_diagnosis_2026_06`,
   M2/RRが最弱）と方向が符合する点は注記に値する。
5. **Rm の逆算**: 離陸直後（最も冷えた状態）の V* から **Rm_cold ≈ 0.36Ω**
   （既存の「旧ファーム値 0.34Ω」と+6.6%差）、飛行後半〜一時停止ペアから
   外挿した飽和値から **Rm_hot ≈ 0.49〜0.59Ω**（既存の「LCR/論文値 0.593Ω」と
   −12%〜0%差）。**「Rm 3値並立問題」は、測定誤差や個体差ではなく
   モータが冷えているか温まっているかの違いだった可能性がある**（5章）。
   ΔR ≈ 0.16Ω(+45%)、銅の温度係数から逆算した巻線温度上昇は **ΔT≈110℃程度**
   （アグレッシブだが物理的に不可能ではない）。
6. **ベンチ測定（LCR・コーストダウン）は、いずれも「冷間」条件だったと確認できた**
   （LCR=無通電=自己発熱なし、コーストダウン=Duty10%を**2秒**駆動しただけで
   カット）。にもかかわらず LCR 値(0.593Ω)は今回の Rm_hot 側に近い——
   したがって「ベンチ=冷間」という前提そのものが崩れている可能性があり、
   **これは新しい未解決の疑問として5章末尾で報告する**（安易に結論しない）。
7. **6.4%ギャップの温度寄与（弱い、参考程度の傍証）**: `vt_ident_study` が
   報告した「ベンチ理論2.680V vs 飛行プール実測2.510V（−6.4%）」の実測値
   2.510Vは、本スタディの Rm_cold(→予測2.44V)と Rm_hot(→予測2.60V)の
   ちょうど中間に収まる。cold-hot中間値のRmを使うと予測2.52Vで実測と
   0.5%差だが、**target(2.510V)自体がRm_cold/Rm_hot予測の範囲内に既に
   収まっているため、この一致は「どの重み付けを選んでも大差ない」弱い
   確認に過ぎず、強い判別力は持たない**（6章で訂正・詳述）。それでも
   「ベンチの0.593Ω基準では実飛行の典型値を系統的に高く見積もる」という
   定性的な向きは支持される。

## 2. 抽出方法

`analysis/scripts/ct_switch_study_20260727/hover_segments.py` と同一の
機械的「定常ホバー」判定（高度move std<0.02m・|vz|<0.10m/s・スティック中立・
duty非飽和、閾値は事前固定・結果を見て調整していない）に、
`flight_state==FLYING` を追加条件とし、最小区間長を1.0秒→**0.5秒**に短縮して
時間分解能を上げた（`extract_timeseries.py`）。ファイルを「連続FLYING区画
(エピソード)」に分割し、各区画の離陸時刻を t=0 とする
`t_since_takeoff_s` を計算した。

95個のホバー区間を19ログから抽出（`hover_timeseries.csv`）。各区間で
V_app,i = duty_i × Vbat（モータ毎）と4モータ平均を記録。

## 3. H1〜H4 判別結果

### 3.1 単一フライト内: H1(熱・飽和指数) vs H2(電圧線形) — 判別不能

3パラメータの飽和指数 `V=V0+dV(1−exp(−t/τ))` を6フライトでフィットしたところ、
**τ が上限(600s、フライト時間の3-4倍)に張り付くケースが大半**——観測窓が
真の時定数に対して短すぎてカーブの曲率を解像できていない。そこで同じ
自由度(2パラメータ)の「時間線形」モデル `V=c0+k·t` を追加し、H2と対等に比較した:

| ログ | n | corr(t,Vbat) | H1(指数)AICc | H1'(時間線形)AICc | H2(電圧線形)AICc |
|---|---|---|---|---|---|
| 020137 (主力) | 27 | −0.992 | −216.2 | −217.4 | **−220.1** |
| 145526 (異常) | 15 | −0.999 | −109.0 | −111.6 | **−111.9** |
| 022929 | 13 | −0.999 | −111.8 | −114.7 | **−115.1** |
| 224906 | 5 | −1.000 | −17.5 | −37.36 | −37.36（実質同値） |
| 231940 | 5 | −1.000 | −10.4 | −30.4 | **−30.3** |
| 173150 | 5 | −0.995 | −11.1 | −31.1 | **−31.3** |

**ほぼ全フライトでH2(電圧線形)がH1(指数)・H1'(時間線形)と同等かわずかに良い
（AICc差は最大でも4未満、多くは1未満。唯一231940だけはH1'がH2よりAICcで
0.08だけ良いが、これはノイズレベルの差であり結論を左右しない）。**
これは「時間で説明できる方が
電圧で説明できるより当てはまりが良い」という判定はできない、という
task-brief の事前警告どおりの結果である。**単一フライトの当てはめ精度だけを
根拠にH1を主張するのは確証バイアス**（時間もVbatも同じ単調減少をしているだけ）
になるため、この結果だけでは判別不能と正直に報告する。

3変数重回帰 `V=a0+b1·Vbat+c1·t` の条件数（標準化後）は15.6〜224——中〜強い
多重共線性を裏付ける（`fit_results_per_flight.csv` 参照）。

### 3.2 一時停止ペア試験 — H1を支持する決定的証拠

同一バッテリ（`ts` 連続=リブートなし）で地上待機を挟んだ2組のフライト対で、
待機直前・直後の生サンプル（strictホバー判定を通らない短時間フライトのため、
`flight_state==FLYING` かつ離着陸遷移前後0.6秒を除外した生値、`pause_pair_raw.py`）
を比較した:

```
2026-06-27 (37.4秒の地上待機、フライトA=ALT_HOLD→フライトB=POS_HOLD):
  フライトA開始(最も冷えた基準点): Vbat=3.989V  V_app=2.4328V
  フライトA終了(待機直前)        : Vbat=3.938V  V_app=2.5045V  (+0.072V, ~10秒で)
  フライトB開始(待機後)          : Vbat=3.933V  V_app=2.4536V  (フライトA開始側へ大きく戻る)

2026-06-22 (30.4秒の地上待機):
  フライトA開始(最も冷えた基準点): Vbat=3.985V  V_app=2.4229V
  フライトA終了(待機直前)        : Vbat=3.950V  V_app=2.4887V  (+0.066V, ~10秒で)
  フライトB開始(待機後)          : Vbat=3.966V  V_app=2.4262V  (フライトA開始側へ大きく戻る)
```

**H2(電圧のみ)による予測との定量比較**（訂正: 初稿は符号を誤って記載していた。
以下は再計算した正しい値）:
- **6/27ペア**: ΔVbat=−0.005V（フライトA終了→フライトB開始）。プール回帰の傾き
  (−0.231〜−0.38 V/V)を適用すると予言されるΔV_appは **+0.0012〜+0.0019V(上昇)**
  ——しかし実際には **−0.0509V(下降)** が観測された。**符号が逆**（予言=上昇、
  実測=下降）。
- **6/22ペア**: ΔVbat=+0.016V（Vbatはむしろ上昇）。同じ傾きから予言されるΔV_appは
  **−0.0037〜−0.0061V(下降)**——符号自体は実測と同じ「下降」だが、実際には
  **−0.0625V** で、**予言の10〜17倍の大きさ**が観測された。

まとめると、2組のうち1組(6/27)は**符号自体が逆転**、もう1組(6/22)は
**符号は合うが大きさが1桁以上過小評価**——いずれの形であれ、H2(Vbatのみ)は
2組とも一時停止直後の急落を説明できない。

**H2だけでは一時停止による V_app の大幅な低下を全く説明できない。
一方H1(熱)は「モータが停止すると急速に冷え始め、Vbatとは独立にV*が
下がる」という直接の予言と定性的・定量的に整合する。** これが本スタディで
最も強い一次データである。

*留意点（フェアネスのため明記）*: 両ペアとも フライトA=ALT_HOLD→
フライトB=POS_HOLDというモード切替を伴う。姿勢トリムの違いで必要推力が
数%変わる可能性はあるが（POS_HOLDの傾き±7°でも cos7°=0.9925=0.75%増と
軽微）、観測された約2-2.5%のV_app低下を説明するには小さすぎる。完全な
反証にはならないが、主要な交絡因子とは考えにくい。

### 3.3 フライト間・Vbat一致点比較 — 交絡ありと判明

異なるログ・日付間で、Vbatがほぼ同じ値(0.05V幅ビン)のときのV_appを比較した
（`fig2_cross_flight_matched_vbat.png`）。**2026-06-29(145526)だけが
Vbat=4.00-4.05Vのビンで V_app≈2.69-2.73V と、他の全フライト
(同ビンで2.40-2.51V)より系統的に+0.2〜0.25V高い。** これは離陸直後
(t=3.35s)から既に高く、H1が予言する「フライト内で徐々に温まる」という
時間発展パターンとは異なる(離陸直後から既に高い=フライト前から温まって
いたか、無関係の理由で最初からV*が高い)。

`vt_ident_study_20260729/proposal.md` §7 は既にこれと同一の現象
(「2026-06-29で+0.21Vの系統誤差」)を独立に報告しており、
**主因として「日付別のセッション間ドリフト（hover.thrust_corrのオンライン
学習値・トリムの違い）」を挙げている**。本スタディの145526は、その直前
(46秒前・別ブート)の`145357`ログで離陸に2回失敗＝短時間のモータ空転を
経験しているため「予備加熱」説も否定はできないが、空転時間はごく短く
物理的な説得力は弱い。**この現象は交絡（hover_thrust_corr差）が主因の
可能性が高く、H1の直接証拠としては採用しない。**

ただし、6/29フライトは**フライト内スロープも最も浅い**
(h1lin_k=0.135mV/s、他フライトは0.60-1.78mV/s)——「離陸時点で既にRmが
高め(熱平衡に近い)だった」という説明ならスロープが浅いことも自然に
説明できる(上昇代が残っていない)。トリム差説だけでは通常スロープの
大小に理由がないため、**わずかにH1側を支持する二次的傍証**として記録するに
留める(確証にはしない)。

### 3.4 モータ別スロープ — 部分的に支持、決定力は弱い

3ポイント以上あるフライトで、モータ毎に頑健な線形回帰(2パラメータ、
3パラメータ指数はV0が境界(1.5V)に張り付くなど不安定だったため不採用)を行った:

```
020137 (n=27, 全4モータ正):
  m1: +0.53 mV/s   m2: +0.46 mV/s   m3: +0.67 mV/s   m4: +0.96 mV/s

022929 (n=13, 3/4が正):
  m1: +0.93 mV/s   m2: -0.39 mV/s   m3: +1.23 mV/s   m4: +0.64 mV/s

145526 (n=15, 2/4が正、全体的にほぼフラット):
  m1: +0.42 mV/s   m2: -0.20 mV/s   m3: -0.06 mV/s   m4: +0.38 mV/s
```

12モータ×フライトの組み合わせ中 **9/12が正**(符号検定、片側二項検定
p≈0.073、有意水準0.05には届かないが示唆的)。M2が2フライト(022929, 145526)
で唯一の負スロープ——`project_motor_fault_diagnosis_2026_06`
(モータ故障診断、「弱いのはCW群、最有力M2/RR」)と方向が符合する点は
偶然の可能性もあるが記録に値する。**4モータ全てが同じ時定数で揃って
上昇する、というクリーンな「教科書的」パターンではなく、支配的な共通トレンド
+モータ個体差、というのが正直な要約。**

### 3.5 H3(推力側の経時変化)・H4(電池内部抵抗)の検討

- **H3(プロペラ空力の経時劣化)**: 本スタディで使えるテレメトリ
  (duty, Vbat, altitude)だけでは、ωを独立に測れないため、
  「Ct/Cqが実際にドリフトしたか」と「Rmがドリフトしたか」は数学的に
  分離できない(どちらも見かけ上「同じωを維持するのに必要なVが増える」
  という同一の観測を生む)。**物理的な事前確率で判断する**: モータ巻線の
  自己発熱は数百mWのI²R損失×1-3分の連続通電で発生する、よく知られた現象
  (ブラシレスモータのデータシートに温度デレーティング曲線が載る理由)。
  一方、小型プラスチックプロペラのCt/Cqが1-3分の使用でアクエロダイナミック
  にドリフトする既知のメカニズムはない(ブレード変形は数十〜数百時間スケール
  の摩耗・熱軟化が普通)。**H1がH3よりも物理的に妥当性が高いと判断するが、
  今回のテレメトリだけでは反証できていない(未確認)。**
- **H4(電池内部抵抗の増大)**: INA3221は電池端子電圧(負荷時)を直接計測して
  おり、Vbatの時系列に電池内部抵抗の影響は既に織り込まれている。
  「INA3221計測点と実効レール電圧の乖離」があるとすれば、それは
  センサ点からモータまでの配線・コネクタ・ESC(FET)のオン抵抗という、
  実質的にH1(モータ側)と数学的に区別できない直列抵抗として現れる。
  **より重要な反証は温度係数の符号**: LiPo/Li-ionセルの内部抵抗は
  一般に温度上昇で**低下**する(電解液のイオン移動度が上がるため、
  RC/EV分野で広く知られる)。もし観測されたV_app上昇の主因が「電池が
  放電で温まって内部抵抗が増える」効果なら符号が逆になるはずで、
  観測(V_app上昇=抵抗上昇)とは矛盾する。**この符号論法はH4(電池起源)を
  積極的に不利にし、正の温度係数を持つ導体(銅巻線・ESCのFETチャネル)
  側の発熱をより強く示唆する。** ただし本スタディのテレメトリだけでは
  モータ巻線とESC FETのどちらが主因かは切り分けられない(未確認)。

## 4. Rm_cold / ΔR / τ_th の推定と「Rm 3値並立問題」への含意

task-brief の定常式 V*=Km·ω_h+(Rm/Km)(Cq·ω_h²+Qf) を使用
（理論値: Km=5.682e-4, Cq=4.10e-11, Qf=9.507e-6, ω_h=3670rad/s。
I_hover=(Cq·ω_h²+Qf)/Km=**0.989A/motor**, EMF項 Km·ω_h=**2.085V**）。

**Rm_cold**（各フライトの離陸直後・一時停止ペアのフライトA開始/B開始、
計7点の平均）: **0.362Ω**（範囲0.341-0.403Ω）
→ **既存の「旧ファーム値 Rm=0.34Ω」と+6.6%差**

**Rm_hot**（020137終盤のプラトー、および一時停止ペアの10秒あたり上昇量
から τ=15/20/30s を仮定して外挿した飽和値、計5点の平均）:
**0.524Ω**（内訳: 020137終盤t=172s単点0.5149Ω、020137終盤プラトー平均0.5004Ω、
τ=15s仮定0.4894Ω、τ=20s仮定0.5232Ω、τ=30s仮定0.5918Ω——後半3つはτの
仮定に依存する外挿値であり独立な測定ではない点に注意）
→ **既存の「LCR/論文値 Rm=0.593Ω」と−11.6%〜0%差**

```
ΔR = Rm_hot − Rm_cold ≈ 0.16Ω  (Rm_coldに対して +45%)
銅の温度係数 α_Cu=0.00393/℃ から逆算した巻線温度上昇:
  ΔT ≈ ΔR/(Rm_cold・α_Cu) ≈ 113℃
```

**「Rm 3値並立問題」への含意（新しい独立証拠）**: これまで
「Rm=0.593Ω(論文LCR実測)」と「Rm=0.34Ω(旧ファーム値、出所不明瞭)」の
どちらが正しいかという二者択一で議論されてきたが（`qa_log.md` Q4-15,
「先生の決定: RはLCRの値でよい」）、**本スタディの結果は両方とも
"正しい"かもしれないことを示唆する——ただし異なる温度条件下での値として**。
0.34Ω(旧ファーム)はコールド・スタート直後(このスタディのRm_cold=0.362Ωと
+6.6%差、実質一致とみなせる範囲)、0.593Ω(LCR)は連続ホバー後半の
温間状態(このスタディのRm_hot=0.49-0.59Ωの範囲内)に対応する可能性がある。

τ_th(熱時定数)は**単一フライト内では識別不能**(指数フィットのτが
上限600sに張り付く=観測窓が短すぎる)。一時停止ペアの「10秒間で
上昇量の大部分が失われた」という事実から、**速い成分の時定数は
τ~15-30秒のオーダーと推定される**(粗い見積り)。ただしフライトが
長くなるほどV_appはなお上昇を続けており(020137終盤でも上昇継続)、
これより遅い第2成分がある可能性も残る——**単一点推定ではなく
オーダー推定として報告する**。

ΔT≈113℃は小型コアレスモータ(質量1-2g級、放熱手段なし)が連続約1A×
1-3分でここまで発熱するのは物理的に「アグレッシブだが不可能ではない」
範囲。**独立検証(サーモグラフィまたは飛行前後のDC抵抗ベンチ測定)が
望ましい**（未確認のまま報告する）。

## 5. ベンチ温度条件の調査結果（`multicopter_introduction/notes/qa_log.md`）

| ベンチ試験 | 直前の運転履歴 | 判定 |

**確認できた事実**: ベンチのコーストダウン・LCR試験はいずれも
「数秒以下の低負荷駆動、または無通電」であり、**実飛行の1-3分連続ホバー
(定常電流~1A/motor×4個)とは自己発熱の蓄積レベルが全く異なる**。
task-brief が示唆した「2秒駆動→コーストなら冷間に近い」という予想は
コーストダウン試験について**そのまま確認された**（実測: まさに2秒）。

**新たな疑問（未解決、6章で正直に報告）**: もしベンチが一貫して冷間条件
だったなら、LCRの0.593Ωは「冷間」の値のはずである。しかし本スタディの
Rm_cold(飛行データからの逆算)は0.362Ωで、LCRの0.593Ωより明らかに低い。
つまり**LCRの0.593Ωは、本スタディのフレームワークでは「冷間」ではなく
「熱間」側の値に対応しているように見える**——これは「LCRは冷間のはず」
という直感と矛盾する。可能な説明（いずれも未検証）:
(a) Km・Cq・Qf・ω_hの理論値自体に系統誤差があり、Rm逆算の基準点
(EMF項2.085V)がずれている、
(b) LCR測定時の室温が通常より高かった、
(c) LCRメータのテスト条件(接触抵抗・4端子でない場合の追加抵抗)が
実効的に高めの値を与えている、
(d) 3月V-ω測定由来のKe=5.53e-4(このスタディが使うKm=5.682e-4とは
別の値)を使うと結果が変わる可能性。
**この不一致は本スタディの範囲では解決せず、「未確認」として明記する。**

## 6. 6.4%ギャップの温度寄与見積り

`vt_ident_study_20260729/proposal.md` は「T=0.0908N/motor(ホバー相当)での
飛行整合V≈2.510V、ベンチ理論V≈2.680V(+6.4%高い)」を報告している。
ベンチ理論値2.680Vは、`motor_chains.py`のNEW_CHAIN定数
(Rm=0.593Ω=LCR値を使用)から計算されている。

本スタディの枠組みで、ベンチ式のRmを実飛行の典型値に置き換えるとどうなるか
試算する（**この試算は判別力が弱いことが後で分かったので、結論を先取りせず
数値をまず並べる**）:

```
本スタディの簡略式(EMF項+I_hover×Rm)でRm=0.593を入れると:
                                            V* = 2.085 + 0.989×0.593 = 2.6715V
  （vt_ident_studyが引用する「ベンチ理論2.680V」とは0.3%差——
    ω_h=3670の丸めや、簡略式(線形)と元のAm·ω²+Bm·ω+Cm(二次項あり)の
    差によるもので、本質的な不一致ではないが、以下の数値も同程度の
    精度でしか主張できない、という較正の目安として明記する）

本スタディ Rm_cold(0.362)を使うと:          V* = 2.085 + 0.989×0.362 = 2.443V
本スタディ Rm_hot(0.524)を使うと:           V* = 2.085 + 0.989×0.524 = 2.603V
本スタディ Rm_cold-Rm_hot単純平均(0.443)*:  V* = 2.085 + 0.989×0.443 = 2.523V

vt_ident_studyの実測プール値:                V ≈ 2.510V
```

**判別力の評価（重要な訂正）**: 実測プール値2.510Vは、Rm_cold予測(2.443V)と
Rm_hot予測(2.603V)の**レンジの中に既に収まっている**。つまり、cold と hot の
どちらへどう重み付けしても(単純平均でなくとも)2.44〜2.60Vのどこかには
収まってしまうため、「単純平均が2.523Vで実測2.510Vと0.5%差」という
一致は、**特定の重み付けが正しいことの証明にはならない、弱い整合性
チェックに過ぎない**。過大に評価しないよう当初案から訂正する。

**それでも定性的に言えること**: (1)実測プール値がRm=0.593(ベンチ)側では
なくRm_cold〜中間域に近い側にあること、(2)ベンチ式(Rm=0.593)がフライト
実測平均より系統的に高いV*を予言すること、の2点は上の数値から読み取れる。
`vt_ident_study`が報告した6.4%ギャップの**向き**（ベンチ>飛行実測）は
「ベンチが実飛行より温間寄りのRmを前提にしている」という本スタディの
知見と整合するが、**ギャップの大きさを定量的に「温度で説明できる割合」
として主張するのは、この試算だけでは根拠不足**と評価を改める。

もしこの定性的な向きが正しければ、`hover.thrust_corr`のデフォルト値を
1.12→0.90へ一律変更するという既存2スタディの提案は、**温度依存のRmを
一定値で近似するための"平均的な帳尻合わせ"という側面を持ち、離陸直後
(モータ冷間)では過剰補正、長時間ホバー後(モータ温間)では補正不足に
なっている可能性がある**——ただしこれも仮説であり、次章で提案する
経過時間を明示的な説明変数とした再回帰でしか検証できない。

## 7. 限界・今後の提案

- **単一フライトのみからの判別は構造的に不可能**（3.1節）。今回は偶然
  見つかった一時停止ペア(2組のみ、いずれも短時間フライト+モード切替あり)
  で判別できたが、サンプル数が少なく、モード切替という交絡も残る。
- **推奨プロトコル**（決定的な追試のため）:
  1. 満充電・モータ冷間で3分連続ホバー(V_app(t)を高分解能で記録)
  2. 着陸し、**冷却時間を10秒・30秒・60秒・120秒と意図的に変えて複数回
     試行**(同一バッテリ・同一日・同一モードで統一し、モード交絡を排除)
  3. 各再離陸直後のV_appが、冷却時間とともに単調にフライトA開始値へ
     近づくかを確認できれば、τ_thを直接・高精度に推定できる
  4. 可能ならモータケースに接触式または非接触(サーモグラフィ)温度計を
     併用し、ΔR⇔ΔTの換算(銅のα)を独立検証する
  5. `current_ma`は本スタディで使用した全ログでNaN(未収録)——
     `ct_switch_study_20260727`が既に指摘した「バッテリ全電流ではなく
     アビオニクス系統のみ」という問題も含め、電流センサ配線の見直しが
     根本的に必要
- **H3(プロペラ空力)は反証できていない**——独立なω計測(フォトインタラプタ
  等)が飛行中にない限り、H1と数学的に分離不可能。
- **6章の"6.4%ギャップ=温度"仮説は粗い近似であり、`vt_ident_study`の
  quasistatic_samples.csv(76,835サンプル)に経過飛行時間を付与して
  再回帰する追試が望ましい**(今回は着手していない、次回への持ち越し)。
