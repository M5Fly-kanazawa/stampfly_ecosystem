# NT金沢ヨー大回転解析スクリプト (2026-06-27 ログ)

2026-06-27 NT金沢展示飛行で目視された「ヨーが180°程度回る」現象の原因分析と対策検証に使ったスクリプト一式。
**分析レポート本体**（結論・対策・図・全数値データ）は `analysis/reports/yaw_nt_kanazawa_20260627/README.md`（git 管理外・ローカル保存）にある。

## 結論の要約

原因は「ヨー制御権限（トルク）の飽和」。(1) CW/CCW モータ群の非対称により静穏ホバー時から平均 0.71 mNm（ソフト上限の36%）をトリムに常時消費、(2) そこへ数秒持続・ピーク 2.1〜2.3 mNm の外乱が重畳するとソフトのヨートルク上限（`max_yaw_torque_`=2.2e-3 Nm）とモータ duty 飽和で差動が頭打ちになり機体が回される。操縦入力・推定器スリップ・ヘディングホールド設計・6/27のゲイン変更はいずれも反証済み。最有効対策はトルク上限の緩和 2.2→2.9 mNm（実測外乱による閉ループシミュレーションで最大偏差 74〜91% 減）。ハード整備は上限緩和とセットで行うこと。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `yawlib.py` | 共通: JSONLパーサ、quat→ヨー角、飛行区間検出。モード対応表は firmware/vehicle の enum とソース照合済み |
| `yaw_event_scan.py` | ヨー回転イベントの自動抽出（8秒窓・往復振幅45°閾値） |
| `drift_analysis.py` | ドリフト形状分類とヘディング目標の逆算（target = ψ + rate_ref/kp） |
| `torque_budget.py` | duty→推力逆変換によるヨートルク収支再構成、外乱 τ_d = I_z·ṙ − τ_yaw、CW/CCW定常非対称の定量 |
| `yaw_cm_sim.py` | 実測 τ_d 駆動の閉ループ・ヨー軸シミュレーション（対策シナリオ S0〜S6 比較） |
| `audit_recalc.py` | シミュレーションの独立再実装による検算（監査用） |
| `skeptic_attack4.py` / `skeptic_attack5.py` | 反証攻撃: ゲイン仮説の反証 / E0 のネイティブ解像度飽和解析 |
| `yaw_events.json` | 抽出イベント一覧（E0〜E5、修正済みモードラベル付き） |
| `cm_sim_results.json` | 対策シミュレーションの数値結果一式 |

## 使い方の注意

- 入力ログは `logs/stampfly_udp_20260627T*.jsonl`（400Hz WiFi テレメトリ、git 管理外）。
- スクリプトは解析セッションのスナップショットで、一部の入出力パスがセッション一時ディレクトリを指したままになっている。再実行時はパスを調整すること。
- 物理定数（I_z, κ, モータ曲線等）は `torque_budget.py` 冒頭に出典 file:line 付きで記載。
