# StampFly 高度制御系モデル — 上下ブレ解析の出発点（2026-07-18）

高度制御の「上下のブレ」修正セッションのための、実コード・実測値ベースのモデル整理。
すべての数値・構造は下記の出典（ファイル）で直接確認済み（2026-07-18 時点の main）。

---

## 1. ブロック図

```
z_ref →(+−)→[位置PID]→ v_cmd →(+−)→[速度PID]→ ΔT_cmd →[B⁻¹ミキサー]→[推力→Duty換算]
              ẑ↑         (±0.5m/s)    v̂↑        (±0.15N)                duty=V/Vbat
                                                                            ↓
                                                        [モータ 1/(τm·s+1), むだ時間]
                                                                            ↓ ΔT
                                              機体鉛直: v̇ = ΔT/m − (dv/m)·v,  ż = v
                                                                            ↓
              ẑ, v̂ ←[相補フィルタ] ← ToF 30Hz ＋ 加速度計積分 400Hz ←──────┘
```

## 2. プラント（実測同定値、2026-07 確定）

$$G(s) \approx \frac{1/m\; e^{-Ls}}{s\,(s + d_v/m)\,(\tau_m s + 1)} \qquad (\Delta T_{cmd} \to z)$$

| 量 | 値 | 出典 |
|----|----|------|
| 質量 $m$ | 36.8 g（$1/m$=27.2 (m/s²)/N、$T_0=mg$=0.361 N） | 実測 |
| 推力感度（4発計） | $8 C_T \omega_0 = 1.97\times10^{-4}$ N/(rad/s) | $C_T$=6.7e-9, $\omega_0$=3670 rad/s（実測） |
| モータ遅れ $\tau_m$ | ≈0.02 s | 飛行同定・コーストダウン整合 |
| 鉛直空力減衰 $d_v/m$ | ≈1.4 1/s（**理論推定・未実測**。誘導速度 $v_h\approx7$ m/s の運動量理論） | 要検証 |
| 計測むだ時間 | ≈33〜50 ms 相当（ToF 30 Hz） | 下記 §4 |

正典値一式: `tools/sysid/defaults.py`、経緯は multicopter_introduction リポジトリ
`notes/qa_log.md`・付録A〜C（Ke=Kt=5.682e-4, R=0.593Ω, C_Q=4.10e-11, κ=6.12e-3,
J_mp=1.375e-8, I=(9.16,13.3,20.4)e-6, d=0.023 m）。

## 3. 制御器（`sf_core/params.cpp` 既定値・400Hz Tustin・条件付き積分）

| ループ | Kp | Ti | 出力制限 |
|--------|----|----|---------|
| 位置 alt_pos | 0.45 [1/s] | 7.0 s | v_cmd ±0.5 m/s（max_climb_rate） |
| 速度 alt_vel | 0.1 [N/(m/s)] | 2.5 s（**フェーズ別スケジュール**: climb=alt_vel_ti / hover=alt_vel_ti_hover） | ΔT ±0.15 N（max_thrust_correction、$T_0$ の 42%） |

- Ti スケジュールの意図（コード注記）: hover の短い Ti は**電池サグの低周波外乱を積分で除去**、
  一律短縮は自動離陸の捕捉オーバーシュートを悪化させるためフェーズ別。
- alt_vel には**外乱オブザーバ（DOB）**がオプトイン実装あり（`altitude.dob.fc`、0=無効）。
- PID 形は姿勢系と同じ `pid.hpp`（PI-D・不完全微分 η=0.125・条件付き積分＋クランプ）。

## 4. 計測系

**訂正（2026-07-19）**: 実機の既定推定器は**15状態 ESKF**（`params.cpp` の
`estimator.type` 既定値 0。1=相補フィルタに差し替え可能、IMU タスクのファクトリが読む）。
以下の相補フィルタ定数は estimator.type=1 のオプション側の記述
（`sf_estimator_complementary/complementary_estimator.cpp`）。
ToF-only 鉛直・baro 非融合の方針は両推定器で共通。

- **鉛直の絶対アンカーは ToF のみ**（気圧計は読むが融合しない設計。M-7 参照。傾き >29° で ToF 棄却）
- ToF VL53L3CX: タイミングバジェット 33 ms = **30 Hz**（`sf_hal_vl53l3cx/include/vl53l3cx_wrapper.hpp`）
- 相補フィルタ: 速い動きは加速度計積分（400 Hz）が担い、ToF 更新ごとに
  `ẑ += 0.30·err`、`v̂ += 0.05·err`（kTofAltGain / kTofVelGain）
- 帰結: **v̂ の質は加速度計に強く依存**（振動・バイアスが直撃）。ToF は 30 Hz の階段。

## 5. アクチュエータ段と電池電圧補償（`sf_actuator/actuator.cpp`）

```
① B⁻¹: T_i = ¼( u_t ± u_φ/d ± u_θ/d ± u_ψ/κ )      κ=6.12e-3（実測値・反映済み）
② 逆モータ曲線: ω=√(T/Ct), V=Am·ω²+Bm·ω+Cm        Ct=1.00e-8, Am=5.39e-8, Bm=6.33e-4, Cm=1.53e-2
③ 電圧補償: duty = V / Vbat                          Vbat = sensor_power.latest().voltage（生値）
④ 安全網: Vbat<2.5V → 公称3.7Vへフォールバック、最終dutyクランプ
```

- 電圧補償は**フィードフォワード**（duty=V/Vbat）。1S LiPo のサグに推力段が追従し、
  SIL のプラント電池サグモデルと整合（Model Identity）。
- **注意1**: `batteryVoltage()` は生値でフィルタが見当たらない（sf_hal_power にも LPF 定数なし）。
  Vbat のノイズ/リップルは duty=V/Vbat 経由で**4モータ同相（＝鉛直推力）に注入**される。
- **注意2**: ②の Ct=1.00e-8・Am 曲線は**飛行ログ較正の連動セット**（実測 Ct=6.7e-9 と別基準）。
  ヘッダ注記「実機ではモータ曲線が約12%推力を過大約束」。→ §8 の SIL 再較正と同根。

## 6. ループ速さの概算（健全性の確認）

- 速度ループ交差: $K_p^{vel}/m = 0.1 \times 27.2 \approx 2.7$ rad/s（0.43 Hz）
- 位置ループ: 0.45 rad/s → 帯域比 ≈ **1/6**（1/3則より保守的・分離は健全）
- むだ時間の位相損失 @2.7 rad/s: ≈6°（この帯域では小さい）
- → **帯域・分離・むだ時間はモデル上は健全**。ブレの主因は別にある可能性が高い。

## 7. 上下ブレの容疑者リスト（優先順）

1. **v̂ の振動汚染** — 速度推定は実質「加速度計の積分」。プロペラ振動が IMU に乗ると
   v̂ が揺れ、alt_vel Kp 経由で推力がチャタつく。§6 が健全な以上、最有力。
2. **Vbat 無フィルタ**（§5 注意1）— 計測ノイズ/リップルの同相注入。更新周期・分散の実測を。
3. **ΔT 飽和 × 積分** — ±0.15 N は T₀ の 42%。離陸・突風時のワインドアップ
   （条件付き積分は入っているが、Ti スケジュールとの相互作用を確認）。
4. **ToF 量子化・ノイズ →（gain 0.30）→ ẑ の 30 Hz 階段 → v_cmd の階段**。
5. **推力→Duty 換算誤差** — ホバ点から外れると実効ゲイン変化（低 Duty で τ_eff は
   100 ms 超に伸びる実測あり）。SIL 検証では旧較正セットがここに直結。
6. **地面効果**（低高度・未モデル化）。
